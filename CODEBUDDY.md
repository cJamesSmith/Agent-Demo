# Project rules

This is a training project for the Uzbekistan AI agent week. Participant packs are in `materials/`. These rules apply to every session.

## Sources

1. Use only the files in the day's pack folder. Do not pull facts from other days, from earlier conversations, or from general knowledge about Uzbekistan.
2. After each conclusion, name the source file in parentheses. A conclusion with no source file is not finished.
3. If a fee, a deadline, a waiting time, or a legal limit is not written in the pack, write "to be confirmed". Do not estimate it, and do not write a plausible number.

## Honesty

4. Separate what the file says, what you inferred, and what you assumed. Never present an inference as a fact.
5. When two files in the same pack disagree, say so and cite both. Do not silently pick one.
6. Do not report that a check passed unless you ran it.

## Boundaries

7. Do not modify anything under `materials/`. Those are read-only source packs.
8. Write deliverables to the working folder the participant names, not into the pack folder.
9. Every centre, meeting, person, and figure in this project is invented for the exercise. Nothing produced here is a government notice or legal advice.
