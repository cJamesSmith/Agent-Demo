# Claim checking

## The table

One row per substantive claim. A substantive claim is any figure, date, deadline, document requirement, or statement that something is already available.

## The four verdicts

**Supported.** A file in the pack states this, with the same meaning, the same units, and the same time period.

**Altered in meaning.** A file supports something adjacent, but the claim as written says more. This is the most common and the most dangerous verdict, because the claim survives a careless check. A source saying a step takes no more than 30 minutes once the application is complete does not support a claim that registration takes 30 minutes. Quote the source wording next to the claim wording so the difference is visible.

**Contradicted.** A file in the pack says otherwise. Name the file and quote the contradicting line.

**Unsupported.** No file in the pack addresses it. Say that plainly. Do not write "partially supported" to soften it, and do not go looking outside the pack.

## When two sources disagree

Do not pick one silently. Report both with filenames and dates, then weigh them on:

- **Who was present.** A group reporting on its own operation is stronger on that operation than a group discussing it in their absence.
- **Which is more recent**, and whether anything changed between the two dates that would explain the difference.
- **Whether first-hand accounts in the pack** agree with one side.

State which you consider better evidence and why. If the disagreement matters to the decision, it belongs in the brief, not in a footnote.

## Claims that need extra care

- A short, attractive figure attached to one step of a longer process. Readers apply it to the whole process.
- "Already live", "now available", "rolled out". Check for a first-hand account saying it has not arrived.
- Averages presented as universal. An average across four areas says nothing about the worst one.
- A figure whose units or period are not stated. Find them before using it, or mark it "to be confirmed".
- Staffing or resource changes reported as done. Check whether the figures show the change.
