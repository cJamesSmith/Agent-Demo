## 规则

1. 材料里没有的费用、时限、法条，写 “to be confirmed”。
2. 第 3 公共服务中心、会议和全部数字都是练习编的。
3. 步骤口径来自 [my.gov.uz](https://my.gov.uz) 上的个人创业者登记，以及 2026 年 1 月起公开报道的 “15 分钟开办企业”：材料齐全之后的登记不超过 30 分钟；电子签名、银行账户、收银机不算在这 30 分钟里。

这些文件不是政府通知，也不是法律意见。
