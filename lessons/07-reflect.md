# Lesson 7: Reflect—From One Demo to Organizational Capability

**Time: 5–10 minutes**

## Final Mental Model

> A Prompt is a one-time instruction, Memory is persistent context, a Skill is a standard method, a Subagent is a specialist role, Planning is a governance boundary, and a Slash Command is a shortcut entry point.

## Reflection Questions

1. Which Memory rule actually changed the website result?
2. Which method from the Skill is most worth reusing in your organization?
3. Which Subagent raised a perspective the main Agent might have missed?
4. Which plan revision prevented rework?
5. What evidence confirmed that the website truly worked?

## Boundaries for Enterprise Adoption

- Classroom data is fictional; real data requires access controls and de-identification.
- Agent recommendations do not replace approval by accountable legal, financial, or business owners.
- External publication, messaging, and production deployment should retain explicit confirmation steps.
- Skills and Subagents are comparable to installing software and delegating to employees; review their instructions and permissions.
- Measure success by correctness, traceability, and rework as well as generation speed.

## Course Completion Criteria

You leave with more than a website. You can also explain:

- Why planning comes first.
- Why Memory should not contain every document.
- How a Skill turns individual expertise into a team asset.
- When Subagents are worth using.
- How review, execution, and recovery control risk.
