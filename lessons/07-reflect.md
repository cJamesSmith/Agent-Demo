# 第 7 课：复盘——从一次演示到组织能力

**用时：5–10 分钟**

## 最终心智模型

> Prompt 是一次性交代，Memory 是持续背景，Skill 是标准方法，Subagent 是专业分工，Planning 是治理边界，Slash Command 是快捷入口。

## 复盘问题

1. 哪一条 Memory 规则实际改变了网页结果？
2. Skill 中哪个方法最值得在公司复用？
3. 哪个 Subagent 提出了主 Agent 容易忽略的观点？
4. 哪个计划修订避免了返工？
5. 你通过什么证据确认网页真的可用？

## 迁移到真实业务

任选一个场景，设计同样的五层结构：

- 季度经营复盘
- 新产品立项
- 投资标的初筛
- 客户流失分析
- 供应商评估
- 组织人才盘点

填写：

```text
业务目标：

需要的 Subagents：
需要先审批的 Planning 决策：
最终交付物：
验证方式：
```

## 企业落地时的边界

- 课堂数据是虚构的；真实数据需经过访问控制和脱敏。
- Agent 的推荐不能替代法律、财务或经营责任人审批。
- 对外发布、发送消息、部署生产等动作应保留明确确认。
- Skills 和 Subagents 相当于安装软件和委派员工，应审查其指令与权限。
- 衡量成功不只看生成速度，也看正确性、可追溯性和返工率。

## 课程完成标准

你不仅得到一个网页，还能解释：

- 为什么先计划；
- 为什么 Memory 不能塞入所有资料；
- Skill 如何将个人经验变成团队资产；
- Subagents 何时值得使用；
- 如何通过审查、运行和恢复控制风险。
