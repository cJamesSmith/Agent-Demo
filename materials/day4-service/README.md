# Thursday task — one service, three products

Training exercise. Use only the files in this folder.

You are the service-design team for “register a home sewing workshop” as an individual entrepreneur at Public Services Centre No. 3, Samarkand.

Produce:

1. `public-page.html` — who can apply, what to bring, the known fee situation, the steps, how to ask about status, how to appeal a refusal.
2. `internal-sop.md` — who does what on which day, when a file is overdue, when it must go to the supervisor.
3. `letters.md` — three short replies, one for each person in `three-cases.md`: accepted, need more documents, refused with a reason.

Rules from `refusal-rules.md`:

- Every fee, deadline, and document must appear in this folder. Otherwise write “to be confirmed”.
- The public page and the internal procedure must use the same number of days.
- Do not use the vague line “incomplete documents” with no document named.
- Add an Uzbek or Russian summary only if someone in the group can check the language.

Two sentences already cleared for public use are in `agreed-sentences.md`. They may be quoted. Do not announce a new pilot.
