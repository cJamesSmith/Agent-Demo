# Refusal rules

Training exercise.

## Allowed activity types at this service

- sewing / making clothes
- repairing clothes
- making home textiles (curtains, bed linen)

Any other activity is refused at this service. The letter must name the activity the person asked for.

## Reasons that must be used when they apply

1. The activity is not on the allowed list above. Say which activity was requested.
2. The workshop address is missing, so the file cannot be accepted.

## Reason that must not be used

“Incomplete documents”, unless the letter names the missing document.

A missing lease is not a refusal. If the room is rented and there is no lease, send the “need more documents” letter and name the lease.
