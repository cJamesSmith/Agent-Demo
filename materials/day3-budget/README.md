# Wednesday task — one pilot, one service area

Training exercise. Use only the files in this folder.

You are in the analytical unit. The leadership can fund only one pilot this quarter:

- more staff
- a simpler form
- a status-tracking page

It can run in only one service area.

Answer:

1. Which pilot, in which service area, and why?
2. Which figures support that choice? Name the sheet and the months.
3. If the priority changes from speed to accuracy, does the same choice still hold?

`avg_days_to_operate` is days from first contact until the resident has a certificate and either an electronic-signature appointment or a submitted bank request. It is not the 30-minute registration click. See the Definitions sheet in `regional-kpis.xlsx`.
